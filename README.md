# SwipeWords

这是一个为 iPhone 设计的极简 PWA 单词/固定句式复习器。

## 使用方式

1. 修改 `vocabulary.js`，把你的单词、chunks、固定句式追加进去。
2. 把整个文件夹部署到任意 HTTPS 静态网站。
3. iPhone 用 Safari 打开网址。
4. 点“分享” → “添加到主屏幕”。
5. 以后直接点桌面图标打开，上滑即可切换下一条。

## 词库格式（2026-11-11）

主词库位于 `vocabulary.js`，截至 2026-11-11 共有 **3,599 张卡片**（包括单词、句型、程度对比词组、完整句子和日语假名）。
所有单词、句型和对比词组均已有自然英文例句；独立句子卡片本身就是完整句子，不再额外附例句。
主词卡使用固定 `id`，即使修改例句，复习进度也能根据 ID 保留。

```js
{
  id: "sw-000001",
  type: "word",
  front: "straightforward",
  meaning: "简单直接、不复杂",
  example: "The route is pretty straightforward from here."
}
```

多义词或程度对比词组可以使用 `type: "group"`，在 `terms` 中分别维护每个用法的 `front`、`meaning` 和 `example`；同一组显示在同一张可纵向滚动的卡片上。

## 当前规则

- 每次打开会重新打乱**本轮尚未复习的**卡片顺序，而不会重置整轮复习。
- 整轮词卡应尽量完整覆盖，未完成前不重新抽取已经学过的卡片。
- 相同卡片具有 100 次滑动冷却规则，复习进度保存在当前设备的浏览器中。
- 向上/向左滑动进入下一张；合并卡片的内容区域允许纵向滚动阅读。
- 右下角 `⋯` 菜单可以管理移出复习的卡片。
- Service Worker 缓存后可离线使用，重新联网时优先更新页面和词库。
- `/english/` 是另一个独立英语复习页面，不与主词库混合管理。

## 本机预览

不要直接双击 `index.html` 测试离线功能。可在该目录运行：

```bash
python -m http.server 8000
```

然后电脑浏览器打开 `http://localhost:8000`。

iPhone 要安装成 PWA，最终建议部署到 HTTPS 地址（例如 GitHub Pages / Cloudflare Pages）。
